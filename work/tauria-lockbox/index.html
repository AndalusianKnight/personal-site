Tauria Lockbox

Zero-knowledge file storage and sharing, close to feature parity with Dropbox.

Role
Founder, CEO & Head of Product
Platforms
Web, desktop, iOS, Android
Benchmark
Dropbox
Outcome
Acquired with Tauria

Overview

Lockbox was where Tauria customers kept the files they couldn't afford to leak: contracts, records, case files. Every file was encrypted on the device before upload, so the storage behind Lockbox only ever held scrambled data.

The benchmark was Dropbox: drag, drop, share, sync everywhere. We wanted all of that without anyone at Tauria being able to open a single file.

Capabilities

  • Encryption on your device before a file ever leaves it
  • Folders and sync across web, desktop and mobile
  • Secure sharing with teammates and outside clients
  • Version history, for when someone saves over the wrong file
  • Files attached in Connect threads and presented in Calls

Design decisions

  • Make the secure way the easy way. Encryption happens automatically, with no extra clicks.
  • Sharing outside the company is where leaks happen, so external shares got the most guardrails.
  • One storage layer for the whole suite, so a file shared in Connect is the same file in Lockbox.

Challenges

  • Sharing an encrypted file with someone outside the company, without the server ever seeing the key.
  • Previews and thumbnails, when the server isn't allowed to look inside the file.
  • Keeping big files fast when every byte is encrypted and decrypted on the device.

Wins & losses

  • Close to feature parity with Dropbox, under zero-knowledge encryption
  • One storage layer behind files across the whole suite
  • Features the server normally does, like previews and search inside files, had to be rebuilt to run on the device
  • Shipped Lockbox inside the suite rather than as a standalone app
